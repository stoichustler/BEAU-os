# Required project skill

For every development, refactoring, debugging, build, review, or code-submission task in this repository, read and follow [`tools/secure-os-dev/SKILL.md`](tools/secure-os-dev/SKILL.md) before taking action.

The `secure-os-dev` skill is mandatory. Its seL4 review rules, Rust modularity requirements, staged workflow, and human-confirmation gates apply to the entire repository. Approval at one gate does not authorize any later gate, commit, push, merge, or submission.
